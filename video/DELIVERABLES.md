# Greenlight video deliverables

| File | Length | Use |
|---|---|---|
| `out/greenlight_demo.mp4` | ≤ 3:00 | The DoraHacks submission video (required) |
| `out/greenlight_teaser.mp4` | ~20s | Social post, made with `brag-slim` |
| `out/captions.srt` | n/a | Burned in and kept as a separate file |

## Export checklist
- 1920×1080, 30 fps, H.264 + AAC, under the platform size limit.
- Captions burned in. Voice-over clear over music.
- Starts on the problem, not the logo.
- Every write-back visible on screen.
- Credit the music (CC BY 4.0, Sascha Ende) if you use `brag`'s bundled tracks.
